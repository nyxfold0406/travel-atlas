# 足迹地图

本地旅行足迹记录工具：世界地球仪 + 中国城市/区县地图，记录去过哪、去了几次、待多久、干了什么。支持行程分组、时间轴回放、照片和游记。

## 功能

- 世界模式：3D 地球仪，拖动旋转，点国家/城市记录
- 中国模式：370 个城市 + 2835 个区县，放大到区县级别
- 记录：每次访问的日期、停留天数/小时、干了什么；景区、出发地、标签、收藏
- 家：最多 3 处，不计入「去过」，作为行程起点/终点
- 行程：按时间自动聚成一段段行程，中间回家会断开
- 回放：选时间段，地点按时间依次点亮，去得越多颜色越深，轨迹线跳着连
- 档案：每个地点可放照片、按日期写游记

## 运行

需要 Windows 10/11、WebView2 Runtime（Win11 自带）、.NET Framework 4.8（系统自带）。

双击 `compile.bat` 编译出 `足迹地图.exe`，双击运行。

## 数据

- `pages/data/travel.json`：所有记录（格式见 `数据接口.md`）
- `pages/data/photos/`：照片

数据只在本机，不上传。

## 数据来源

- 世界国界：Natural Earth 1:110m（公有领域）
- 世界城市点：Natural Earth populated places
- 中国省 / 市 / 区县：阿里 DataV GeoAtlas
